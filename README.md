# Glow Beauty Salon

A responsive salon website with an online appointment enquiry system and owner dashboard.

## Features

- Service information
- Online appointment requests
- WhatsApp contact button
- Direct call button
- Owner login
- Customer enquiry dashboard
- Search enquiries
- Filter enquiries by status
- Update enquiry status
- Delete enquiries
- Mobile-friendly design
- Supabase database integration

## Tech Used

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Live Website

https://niharika708.github.io/glow-beauty-salon/

## Project Purpose

This project demonstrates a small-business website with a working customer enquiry system and an owner dashboard.
